# 01 - Functions

## What I Learned
A function is a named block of code that takes input, does work, and optionally returns output.

## Key Concepts
- Function declaration: `function name(param) { return value; }`
- Arrow function: `const name = (param) => value;`
- Implicit return: arrow functions with a single expression skip the `return` keyword

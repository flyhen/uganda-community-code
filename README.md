# Uganda Community Code

Building technical skills to solve practical problems in my community.

This repository documents my journey learning JavaScript from first principles, using the **hand-teaches-brain** method: writing logic on paper before touching an IDE.

## 🎯 Mission

Build offline-first, low-resource tools for community challenges in Uganda.

Every drill, every topic, every line of code is a brick in the foundation of a real tool: a meal distribution tracker for community programs.

## 🧠 Method

- **Hand-written drills first** — black, blue, red pens.
- **Copy → Recall → Modify → Create** — four stages of mastery.
- **One repo, structured by phase** — each topic builds on the one before.

Why Low-Resource Tech
In environments where network drops are common and devices are budget-range, code must be:

Offline-first — works without internet

Lightweight — runs on cheap smartphones

Resilient — handles errors gracefully

Simple — easy to maintain and modify

This repository is my training ground for building that kind of software.

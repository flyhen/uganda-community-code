# 02 - Arrays

## What I Learned
An array is an ordered list of values. It lets me store and manage multiple items under one name.

## Key Concepts
- Creating: `let list = ["item1", "item2"];`
- Reading: `list[0]` (starts at 0)
- Adding: `.push()`
- Removing: `.pop()`
- Counting: `.length`
- Finding: `.indexOf()`
